## Integrity verification (2026-10-14)

`scripts/fish verify --deep` — all **16/16** files: byte length equal to the
Hugging Face tree at the pinned revision, and content hash equal to the
upstream value (SHA-256 = LFS oid for the 7 LFS files; git blob SHA-1 for the
9 others). `MANIFEST.json` was generated by `scripts/make-fish-manifest.py`
from the Hugging Face API at that revision; its own SHA-256 is part of the
engine's identity, so a running engine can be matched to this record.

## Runtime compatibility
